# Styling & Theming

## Theme Support

FxLayout components support the Sapphire theme system with light/dark modes and color variants.

### Theme Provider Setup

```tsx
import { ThemeProvider } from '@sap-ui/fx-components';

const THEMES = [
  { id: 'light', name: 'Light', category: 'Standard' },
  { id: 'dark', name: 'Dark', category: 'Standard' },
  { id: 'system', name: 'System', category: 'Standard' },
];

<ThemeProvider themes={THEMES}>
  <App />
</ThemeProvider>
```

### Using Theme

```tsx
import { useTheme } from '@sap-ui/fx-components';

function ThemeSelector() {
  const { theme, setTheme, resolvedTheme } = useTheme();

  return (
    <select value={theme} onChange={(e) => setTheme(e.target.value)}>
      <option value="light">Light</option>
      <option value="dark">Dark</option>
      <option value="system">System</option>
    </select>
  );
}
```

## CSS Classes

### Semantic Color Classes

Use shadcn semantic classes for consistent theming:

```tsx
// Text
<span className="text-foreground">Primary text</span>
<span className="text-muted-foreground">Secondary text</span>

// Backgrounds
<div className="bg-background">Main background</div>
<div className="bg-muted">Muted background</div>
<div className="bg-card">Card background</div>
<div className="bg-accent">Accent background</div>

// Borders
<div className="border-border">Default border</div>
```

### Palette Classes

Palette tokens (`--color-*` in tokens.css) register directly in Tailwind — no `sapphire-` prefix:

```tsx
// Purple scale
<span className="text-purple-500">Purple accent</span>
<div className="bg-purple-100">Light purple surface</div>

// Blue scale
<span className="text-blue-600">Blue accent</span>

// Neutrals
<span className="text-neutral-700">Tertiary text</span>
<div className="bg-neutral-100">Subtle surface</div>
```

### Spacing Classes

Spacing tokens (`--spacing-*` in tokens.css) are registered with a `sapphire-` prefix to avoid clashing with Tailwind's built-in sizes:

```tsx
<div className="p-sapphire-3xs">4px padding</div>
<div className="gap-sapphire-s">16px gap</div>
<div className="m-sapphire-xl">32px margin</div>
```

### Sapphire Semantic Classes

For Sapphire-specific tokens not covered by shadcn:

```tsx
// Text levels
<span className="text-sapphire-text-tertiary">Tertiary text</span>
<span className="text-sapphire-text-disabled">Disabled text</span>

// Surfaces
<div className="bg-sapphire-background-tertiary">Tertiary surface</div>
<div className="bg-sapphire-canvas-primary">Canvas background</div>

// Notifications
<span className="text-sapphire-positive">Success</span>
<span className="text-sapphire-negative">Error</span>
<div className="bg-sapphire-info-bg">Info background</div>

// Chrome (navigation)
<div className="bg-sapphire-chrome-bg-primary">Navigation background</div>
<span className="text-sapphire-chrome-fg-primary">Navigation text</span>

// Prompt (Joule)
<span className="text-sapphire-prompt-accent">Prompt icon</span>
<div className="border-sapphire-prompt-accent-muted">Prompt border</div>
```

### Avoid Hard-Coded Colors

❌ Don't use:
```tsx
<span className="text-green-500">Success</span>
<div className="bg-orange-100">Warning</div>
```

✅ Do use:
```tsx
<span className="text-sapphire-positive">Success</span>
<div className="bg-sapphire-warning-bg">Warning</div>
```

## Token Architecture

The theme system has three layers:

```
tokens.css (values)  →  sapphire-theme.css (@theme)  →  Tailwind utility classes
```

### tokens.css — Source of Truth

Defines all CSS custom properties in `:root` (light) and `.theme-dark` (dark). Base palette colors are defined once and semantic tokens derive from them via `var()`:

```css
:root {
  --color-brand-purple: #5D36FF;                               /* base */
  --color-purple-500: hsl(from var(--color-brand-purple) ...); /* derived */
  --prompt-accent: var(--color-purple-500);                    /* semantic */
}
```

### sapphire-theme.css — Auto-Generated

**Do not edit this file manually.** It is fully generated by `scripts/sync-theme-tokens.mjs` from tokens.css on every build.

Naming rules:
| Token prefix | @theme variable | Tailwind class |
|---|---|---|
| `--color-*` (palette) | `--color-purple-500` (direct) | `bg-purple-500` |
| `--spacing-*` | `--spacing-sapphire-3xs` (prefixed) | `p-sapphire-3xs` |
| Core shadcn | `--color-background` (direct) | `bg-background` |
| Semantic | `--color-sapphire-{name}` (prefixed) | `bg-sapphire-prompt-accent` |

### Adding New Tokens

1. Add the token to `tokens.css` in both `:root` and `.theme-dark`
2. Run `npm run build` (the sync script runs automatically)
3. The new Tailwind utility class is immediately available

No need to touch `sapphire-theme.css` — it regenerates automatically.

## Layout Dimensions

The layout uses CSS variables for responsive dimensions:

```css
/* Navigation rail */
--fx-nav-width-collapsed: 56px;
--fx-nav-width-expanded: 220px;

/* Pane widths */
--fx-start-pane-width: 280px;
--fx-end-pane-width: 320px;

/* Responsive breakpoints (main area width, not viewport) */
/* 3 panes: ≥1965px, 2 panes: ≥1020px, 1 pane: <1020px */
```

## Custom Styling

### Header Actions

Style action buttons using the `className` prop:

```tsx
<FxPaneHeaderAction
  icon={<Plus />}
  text="New"
  className="my-custom-button"
/>
```

### Pane Content

Style pane content areas:

```tsx
<FxLayout
  startContent={
    <div className="p-4 space-y-2">
      {/* Your styled content */}
    </div>
  }
/>
```

### Input Styling

Style the prompt input:

```tsx
<FxPromptInput
  className="my-custom-input"
  placeholder="Ask..."
/>
```

## Animations

### Subheader Animation

The search subheader in el-demo uses CSS animations:

```css
@keyframes subheader-enter {
  from {
    opacity: 0;
    transform: translateY(-8px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

@keyframes subheader-exit {
  from {
    opacity: 1;
    transform: translateY(0);
  }
  to {
    opacity: 0;
    transform: translateY(-8px);
  }
}
```

```tsx
<div
  style={{
    animation: searchExiting
      ? 'subheader-exit 0.3s cubic-bezier(0.4, 0, 0.2, 1) forwards'
      : 'subheader-enter 0.3s cubic-bezier(0.4, 0, 0.2, 1)',
  }}
>
  <Input ... />
</div>
```

### Pane Transitions

Pane visibility transitions are handled internally by FxLayout using CSS transitions for smooth open/close animations.

## RTL Support

For right-to-left languages, use the I18nProvider:

```tsx
import { I18nProvider } from '@sap-ui/fx-components';

<I18nProvider locale="ar-SA" dir="rtl">
  <App />
</I18nProvider>
```

The layout automatically mirrors for RTL:
- Navigation rail moves to the right
- Pane order reverses
- Icons and text align appropriately

## Dark Mode

Dark mode is automatically applied based on the theme setting. Components use semantic color tokens that switch automatically.

To manually detect dark mode:

```tsx
const { resolvedTheme } = useTheme();
const isDark = resolvedTheme === 'dark';
```
