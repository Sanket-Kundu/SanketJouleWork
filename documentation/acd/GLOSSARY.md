# Glossary

| Term / Abbreviation | Definition / Meaning |
|---|---|
| a11y | Accessibility — numeronym for the word "accessibility" (a + 11 letters + y) |
| ACD | Architecture Concept Document — SAP standard document describing the architecture of a software product |
| ARIA | Accessible Rich Internet Applications — W3C specification for making web content accessible to assistive technologies |
| BTP | SAP Business Technology Platform — SAP's cloud platform for building and extending enterprise applications |
| CF | Cloud Foundry — open-source platform-as-a-service used within SAP BTP for application deployment |
| CI/CD | Continuous Integration / Continuous Delivery — practice of automating build, test, and deployment pipelines |
| CJS | CommonJS — JavaScript module format using `require()` / `module.exports`, used by Node.js |
| CLI | Command-Line Interface — text-based interface for interacting with software |
| CSS | Cascading Style Sheets — language for describing the presentation of HTML documents |
| CVA | Class Variance Authority — utility library for managing component variant classes in a type-safe manner |
| DX | Developer Experience — the overall experience developers have when using a library, tool, or API |
| ESM | ECMAScript Modules — the official JavaScript module format using `import` / `export` syntax |
| Fiori | SAP Fiori — SAP's design system and UX guidelines for enterprise applications |
| FxLayout | The responsive multi-pane layout system in fx-components, ported from the Web Component reference implementation |
| HMR | Hot Module Replacement — development feature that updates modules in-place without a full page reload |
| i18n | Internationalization — numeronym for the word "internationalization" (i + 18 letters + n) |
| i18next | An internationalization framework for JavaScript that provides translation loading, interpolation, and namespace-based resource management |
| JSX | JavaScript XML — syntax extension allowing HTML-like markup inside JavaScript/TypeScript files |
| LTR | Left-to-Right — text direction for languages such as English, German, and French |
| NPM | Node Package Manager — the default package manager for Node.js, also refers to the public registry at npmjs.com |
| Namespace (i18next) | A logical grouping of translation keys in i18next; fx-components uses the "fx" namespace to isolate its 131 translation keys from application or shell translations |
| QAS | Quality Attribute Scenario — structured description of a quality requirement including stimulus, response, and measure |
| React | A JavaScript library for building user interfaces, maintained by Meta |
| react-i18next | React bindings for i18next, providing the useTranslation() hook for accessing translations in React components |
| RTL | Right-to-Left — text direction for languages such as Arabic and Hebrew |
| Sapphire | SAP's visual design language providing design tokens, color palettes, and typography guidelines for SAP applications |
| SAST | Static Application Security Testing — automated analysis of source code for security vulnerabilities |
| shadcn/ui | A collection of re-usable React components built with Radix UI and Tailwind CSS, used as a pattern reference |
| TAM | Technical Architecture Modeling — SAP's diagramming notation for architecture documents |
| Tailwind CSS | A utility-first CSS framework that provides atomic CSS classes for styling |
| tree-shaking | Dead-code elimination technique used by bundlers to remove unused exports from the final bundle |
| tsup | A zero-config TypeScript bundler powered by esbuild, used to build the library |
| TSX | TypeScript XML — TypeScript files containing JSX syntax |
| Vite | A modern frontend build tool providing fast HMR and optimized production builds |
| WCAG | Web Content Accessibility Guidelines — W3C standard for making web content accessible (target: Level AA) |
| XSS | Cross-Site Scripting — a security vulnerability where malicious scripts are injected into web content |
